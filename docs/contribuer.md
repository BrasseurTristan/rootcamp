# Contribuer

Tu as une idée de panne à faire réparer, une fiche à améliorer, une erreur à
signaler ? Toutes les contributions sont les bienvenues.

- **Signaler un problème ou proposer une idée de lab** : ouvre une
  [issue](https://github.com/BrasseurTristan/rootcamp/issues).
- **Créer un lab** : le format et les conventions sont décrits dans
  [CONTRIBUTING.md](https://github.com/BrasseurTristan/rootcamp/blob/main/CONTRIBUTING.md).
- **Corriger une fiche** : clique sur le crayon en haut à droite de la page.
